# VXA Complete Experience Slice Map

Binding: `FORGE-VEXRYZER-AUTOMATION-v1.0.0`
Initiative: `VXA-001`

## VXA-S001 — Foundation + Infinite Canvas

Observable result: a visitor opens an ultra-premium responsive infinite canvas, navigates it fluently and experiences deterministic camera transitions and process nodes without AI.

Scope: repository/product foundation under `job/`, Vite/React/TS strict, design tokens, canvas shell, camera director, node system, semantic zoom, desktop/mobile behavior, reduced motion, accessibility foundation, performance instrumentation, visual baseline.

GAUNTLET: `GNT-VXA-S001-001`.

## VXA-S002 — ASK AI Discovery

Observable result: the visitor converses with ASK AI and validated process understanding materializes in the canvas.

Scope: Mistral server-side integration, streaming UX, structured extraction, XState dialogue lifecycle, provenance, corrections, ambiguity, multiple processes, concise question policy, prompt injection defenses, AI failure fallback.

GAUNTLET: `GNT-VXA-S002-001`.

## VXA-S003 — Qualification + Value + Pricing

Observable result: the experience derives monthly person-hours, visualizes accumulated impact and presents a deterministic estimate at the correct confidence threshold.

Scope: frequency normalization, multiple-person effort, recurring/single/seasonal distinctions, Value Lens, server-side pricing, estimate confidence, price-first paths, objection handling, commercial policy and CTA progression.

GAUNTLET: `GNT-VXA-S003-001`.

## VXA-S004 — Evidence

Observable result: example files can be requested and uploaded within the canvas, safely persisted and represented as evidence without blocking visitors who lack files.

Scope: Netlify Blobs, upload lifecycle, limits, format validation, safe names/keys, replacement, recovery, privacy copy, production/non-production storage separation, retention strategy.

GAUNTLET: `GNT-VXA-S004-001`.

## VXA-S005 — Close + Durable Submission

Observable result: a real request is reviewed, sealed durably, assigned a protocol and notified internally without email availability becoming a single point of loss.

Scope: minimal contact capture, review canvas, request manifest, protocol, idempotency, seal semantics, notification provider, retry/pending semantics, final receipt.

GAUNTLET: `GNT-VXA-S005-001`.

## VXA-S006 — Conversion + Production Hardening

Observable result: the full product survives adversarial, accessibility, performance, mobile, browser, outage and commercial-conversion review and is deployable on Netlify Free.

Scope: complete interaction matrix, analytics events, abuse protection, quota guards, security headers, browser/device matrix, performance budgets, visual review, conversion review, production deployment, smoke tests and rollback evidence.

GAUNTLET: `GNT-VXA-S006-001`.

## Dependency chain

`S001 -> S002 -> S003 -> S004 -> S005 -> S006 -> candidate freeze -> final GAUNTLET -> production`.

No requested capability is intentionally deferred outside this map.
